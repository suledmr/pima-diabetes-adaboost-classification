# Pima Indians Diabetes Classification using AdaBoost

This project builds a machine learning classification model using AdaBoost on the Pima Indians Diabetes dataset.

## Project Overview

The goal of this project is to predict whether a patient has diabetes based on medical diagnostic features.

## Dataset

Dataset source: Kaggle - Pima Indians Diabetes Database

Dataset link: <https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database>

## Features

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## Project Steps

- Data loading
- Data preprocessing
- Handling zero or missing-like values
- Exploratory Data Analysis (EDA)
- Feature scaling
- Model training with AdaBoost
- Model evaluation

## Model

AdaBoost Classifier is used for diabetes classification.
